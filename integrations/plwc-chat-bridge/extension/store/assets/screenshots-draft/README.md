# PLwC Store Screenshot Drafts

These PNG files are non-destructive, privacy-sanitized working copies derived
from the repository-root `screen1.png` through `screen5.png` captures. All five
working copies are exactly 1280 x 800 pixels and therefore use the common
Chrome Web Store / Microsoft Edge Add-ons screenshot size.

They are **draft material, not final Store acceptance evidence**. The content
was adjusted with AI-assisted raster editing to replace private profile names,
workspace paths, call identifiers, and conversation content with synthetic
demo values. Text and UI state must therefore be checked against a fresh
capture from the final Store-identity build before submission.

| File | Intended use | Current status |
| --- | --- | --- |
| `01-status-and-result-draft-1280x800.png` | Status and synthetic result composition | Store candidate draft |
| `02-tools-overview-draft-1280x800.png` | Public 8/8 tool overview | Store candidate draft |
| `03-policy-and-status-draft-1280x800.png` | Execution policy and synthetic runtime status | Store candidate draft |
| `04-configuration-draft-1280x800.png` | Shared PLwC configuration | Documentation/supporting draft |
| `05-getting-started-draft-1280x800.png` | Local getting-started guide | Documentation/supporting draft |

The three Store-candidate drafts satisfy the formal screenshot count and the
shared Chrome/Edge size contract. The five-shot plan in `../../listing-en.md`
is an optional stronger evidence set, not an additional Store upload minimum.
Before submission, compare the chosen drafts once against the current 1.0 UI;
do not label AI-adjusted images as live Store-ID acceptance evidence.
